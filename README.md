# 趣站博物馆

Sitopia 是 [有趣网址之家](https://youquhome.com/) 的一座浏览器展厅。人站在广场上，走进白墙楼，沿墙看画框。画框来自门户的四个分类：千奇百怪、轻松好玩、在线应用、公益宣传。同一层按这个顺序往里接，一层挂满再往上加。走近一只画框点一下，能看介绍、原文和传送门。

用电脑和键鼠打开。手机上能看，不适合逛。

线上展厅：https://sitopia.youquhome.com/

仓库：https://github.com/wenxiuncle/Sitopia

## 技术栈

- 页面是原生 JavaScript 模块。三维场景用仓库里自带的 Three.js r170（`vendor/three.module.js`），克隆下来即可打开，不必安装依赖，也不经过打包。
- 站名、介绍和厅名写在 HTML 浮层里。画框、墙、地板是 Three.js 网格。
- 展品从有趣网址之家的 WordPress 接口拉取，写入 `data/sites.json`。画芯用文章配图，浏览时向 `img.youquhome.com` 跨域读取，按人所在的楼层合成到画框共用的图集上。
- 本机用 Node.js 起页面（`tools/serve.mjs`）。一起逛走 WebSocket：线上房间是 Cloudflare Workers 的 Durable Object（sitopia-lobby），经 `lobby.youquhome.com` 反代；本机另有一间，和线上不是同一拨人。静态页面放在 GitHub Pages 上。
- 馆内琴声播放 `audio/` 里的钢琴曲，进度以联机房间为准，循环播放。展厅没人时暂停，有人进来再接着放。萨蒂《Gymnopédie》第一首的录音为公有领域，说明在 `audio/来源.txt`。广场的风、鸟叫、脚步和电梯是现场合成的，没有另外的录音。
- 馆的代码以 GPL-3.0 发布。Three.js 仍是它文件头里的 MIT。

## 玩法特点

进馆前先起一个名字。`W` `A` `S` `D` 走动，鼠标环顾，按住 `Shift` 快步。默认第一人称，`V` 换成第三人称；第三人称时按住 `Alt` 可以环视。

画框分上、中、下三排，按文章从新到旧排列。点一只画框，左下角浮出这篇的介绍。有站外传送门就能进那个站；原文标了已挂的，浮层上会写明。没有站外链接时，只留有趣网址之家原文。

上下楼可以走楼梯，也可以坐电梯。电梯门外按 `E` 开门，轿厢里按 `F` 选出楼层，点好就继续走。`R` 回到广场。二楼起，每层门口有朝向广场的观景台。

左上角或 `[` `]` 切换时辰，从清晨到夜晚。走进厅内会响起一组钢琴，进度跟联机房间走：厅里没人就停，有人进来接着放。走到广场或观景台上音量淡出。广场有风声和偶尔的鸟叫，夜晚没有鸟；脚步分广场、馆内和楼梯；电梯有按键、门、机械和到层的声音。`M` 一起关掉。

右上角是平面图和在线人数。别人在馆里是一个方块人，话会出现在头上，也留在聊天记录里。菜单里可以改成单人模式。按键表在下面的「怎么逛」。

## 独到之处

门户上这两千多篇文章挂在同一座能走的楼里。分类、楼层、电梯和平面图把人送到对应的墙前，介绍用的就是门户原文。

全部画框是一对实例化网格。配图按人所在的楼层画进同一张图集，邻近楼层会预先去要。墙、地板和画框用基础材质。时辰改变天空和室外的明暗，屋顶的影子落在广场上；厅内则是天花板上的灯锥。

展品和门户文章保持同一份。传送门取开篇里的链接，划掉的旧网址仍留在框上，并标成已挂。定时任务会把新文章写回清单。

一个人可以逛完。联机房间只同步谁在、站在哪、说了什么。离开页面之后，名字还会在在线名单上留大约三十秒。

## 在本机打开

需要已安装 Node.js。双击 `start-museum.bat`，或在这个目录里运行：

```bash
node tools/serve.mjs
```

浏览器打开 http://127.0.0.1:4173/ 。换端口可以设环境变量 `PORT`。

进馆前先起一个名字，以后点地图下面的在线人数改。本机打开时，同一个服务里的窗口互相看得见。线上页面的一起逛走 `wss://lobby.youquhome.com/lobby`，再转到 Cloudflare 的 sitopia-lobby，和本机不是同一间。有趣网址之家 `/sitopia/` 是另外传上去的，不跟这次仓库一起换。

## 怎么逛

点击画面之后鼠标才锁定。

- `W` `A` `S` `D` 走动，鼠标环顾，`Shift` 快步
- 单击画框，看介绍和链接。点卡片外面，鼠标回到走动。离开这个页面，人还会在线三十秒
- `回车` 说话。发出去的字出现在左下角，最新的在最上面，最多五行，也出现在头上。再按一次 `回车`，输入框收起
- 左上角按钮，或 `[` `]`，从清晨换到夜晚
- 右上角是平面图。地图下面，电梯和在线人数并排，宽度跟地图对齐，点一下换一个。`Tab` 或右上角三条横线打开导航
- 点在线人数，看谁在、聊天记录，改名字。再点一次才收起
- 电梯门外和轿厢里按 `E` 开门。轿厢里按 `F` 打开右侧楼层，点一层就选上并继续走，鼠标收回，再点一次取消，出电梯才收起
- `R` 回到广场
- `Esc` 才出现左下角说明和右下角操作说明。左下角有各分类的数量。点说明外面继续走

地址后面可以加参数：`?preview=1` 相机对着一只画框，`?time=清晨` 指定时辰，`?debug=1` 画出碰撞线。

## 展品从哪来

`data/sites.json` 是当前这份清单，字段有标题、简介、传送门、原文、分类，有配图时还有图片地址。传送门取自有趣网址之家原文开篇；原文标了已挂的站仍保留。

重新拉文：

```bash
node tools/fetch-sites.mjs
```

给当前墙上的画框补上配图地址：

```bash
node tools/fetch-sites.mjs --images
```

改完布局或清单后跑一遍：

```bash
node tools/selftest.mjs
```

配图不放进这个仓库。运行时向 `img.youquhome.com` 要图，图片站需要允许跨域读取。

## 目录

| 路径 | 内容 |
| --- | --- |
| `index.html`、`museum.css` | 页面和浮层 |
| `js/` | 展厅、走动、时辰、在线的人 |
| `tools/serve.mjs` | 本机打开，并带上同一台电脑上的联机 |
| `worker/lobby.js` | 一起逛的房间，Cloudflare 上的 sitopia-lobby |
| `worker/youqu-proxy.js` | `lobby.youquhome.com` 的反代，转到上面的房间 |
| `server/youqu-lobby/index.php` | 有趣网址之家那份房间。仓库里留着，这次不传到主机 |
| `tools/fetch-sites.mjs` | 从有趣网址之家拉展品 |
| `tools/selftest.mjs` | 检查布局、朝向和能不能走到 |
| `data/sites.json` | 展品清单 |
| `vendor/three.module.js` | Three.js r170，许可在文件头 |

Three.js 已经放在仓库里，不需要 `npm install`。
